# Projeto Final - Técnicas de Programação I (PY)

## Sobre o projeto

Este projeto foi desenvolvido como trabalho final do curso Técnicas de Programação I
O objetivo é realizar uma análise exploratória de dados utilizando Python, Pandas, NumPy e Matplotlib sobre as candidaturas das Eleições de 2022.

## Bases utilizadas

### Link:
https://dadosabertos.tse.jus.br/dataset/candidatos-2022

### Base principal:
consulta_cand_2022_BRASIL.csv: contém informações gerais das candidaturas

### Base auxiliar:
consulta_cand_complementar_2022_BRASIL.csv: utilizada para informaçãoes de idade e valor de despesa
